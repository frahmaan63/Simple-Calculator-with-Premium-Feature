# Simple Calculator with Premium Feature
Created by Fathur Rahmaan, This project was originally developed as an assignment for a Basic of Programming course.
This "Simple Calculator with Premium Features" is built using the Python programming language and incorporates several data types, including:
1. *Set* – used to store valid "redeem codes," which can be entered to unlock access to premium features.
2. *Integer* – used in the basic calculator to represent whole numbers without decimal points.
3. *Arithmetic Operators* – used to perform mathematical calculations such as addition, subtraction, multiplication, division, modulus, and floor division.
4. *If-Elif-Else Statement* - Digunakan dalam kalkulator basic atau premium untuk menyatakan pernyataan berdasarkan opsi fitur yang dipilih user
5. *Recursive Functions* -> A feature within the premium Calculator that includes the Fibonacci sequence, factorials, and exponentiation.

# How To Use It
The program will run in the VS Code terminal and follow these steps:
1. Select the type of calculator you wish to use (Basic Calculator or Premium Calculator).
2. If you choose the Basic Calculator, enter two numbers and an available operator; the calculation result will then be displayed.
3. If you choose the Premium Calculator, it is recommended to first select option 3 to redeem a code (using the code in `REEDEM_CODE`) afterward, you may select the specific feature you are going to use.
4. Press CTRL + C to stop the program when you are finished.

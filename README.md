# Simple Calculator with Premium Feature
Created by Fathur Rahmaan, This project was originally developed as an assignment for Basic of Programming course.
This project is built using Python programming language and incorporates several data types, including:
1. *Set* – used to store valid "redeem codes," which can be input to unlock access to premium features.
2. *Integer* – used in the basic calculator to represent whole numbers without decimal points.
3. *Float* - used in premium calculators to represent decimal numbers.
4. *Arithmetic Operators* – used to perform mathematical calculations such as addition, subtraction, multiplication, division, modulus, and floor division.
5. *If-Elif-Else Statement* - Used in basic or premium calculators to present statements based on the feature options selected by user.
6. *Recursive Functions* -> A feature within the premium Calculator that includes Fibonacci sequence, factorials, and exponentiation.

# How To Use
The program will run in VS Code terminal by following these steps:
1. Select the type of calculator you want to use (Basic Calculator or Premium Calculator).
2. If you choose the Basic Calculator, input two numbers and choose an available operator, the calculation result will then be displayed.
3. If you choose the Premium Calculator, it's recommended to first select option 3 to redeem a code (using the code in `REDEEM_CODE`) afterward, you may choose the specific feature you want to use and input the number.
4. Press CTRL + C to stop the program when you are finished.
